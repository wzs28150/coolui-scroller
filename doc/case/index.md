# 示例 demo

coolui-scroller 的完整示例工程都在仓库里，扫码或用微信开发者工具打开即可预览。

请微信扫码打开小程序查看：

<img src="/images/demo.jpg" alt="示例小程序码" />

## 获取源码

```bash
git clone https://github.com/wzs28150/coolui-scroller.git
```

| 工程 | 说明 |
| --- | --- |
| `demo/native` | **原生微信小程序**示例，用微信开发者工具直接打开该目录 |
| `demo/uniapp` | **uni-app** 示例（Vue3 + Vite，已配置 easycom 与自动导入）。执行 `pnpm --filter demo-uniapp dev:mp-weixin` 后，用微信开发者工具打开 `demo/uniapp/dist/build/mp-weixin` |
