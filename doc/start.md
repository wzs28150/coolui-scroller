# 选择你的平台

coolui-scroller 提供两个版本，**组件能力与配置项一致**，差别只在引入方式与个别平台差异。

<PlatformCards />

::: tip 进入文档后可以随时切换
文档站顶部有平台切换器：切换时会停在同一位置在另一平台的对应页面（组件文档会落到组件总览的对应锚点），站点会记住你的选择。
:::

## 该用哪个？

| 你的项目 | 用哪个版本 |
| --- | --- |
| 微信小程序原生项目（微信开发者工具直接开发，不走 uni-app 编译） | **原生微信小程序版** `coolui-scroller` |
| uni-app 项目（Vue2 / Vue3），需要同时编译到小程序 / H5 / App | **uni-app 版** `coolui-scroller-uni` |
